# Airmail Courier

A whimsical, interactive e-card website created as an ITWS02 laboratory project submission.

## About

This project is a personalized, interactive greeting card styled with a Studio Ghibli-inspired postal delivery theme. It features an interactive wax seal with playful animations, procedural ambient sound effects, and an encrypted letter presentation.

This project was built strictly for academic and laboratory demonstration purposes for the ITWS02 course.
